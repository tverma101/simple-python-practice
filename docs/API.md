# API Reference

## Overview

This document provides a reference for Ducky's internal APIs and HTTP endpoints.

## HTTP Server API

### Base URL

```
http://TEACHER_IP:8420
```

### Authentication

All requests require a Bearer token in the Authorization header:

```
Authorization: Bearer <access_code>
```

The access code is a 9-digit number generated by the teacher.

---

### Endpoints

#### POST /api/connect

Connect a student to the teacher server.

**Request:**
```json
{
  "name": "Student Name",
  "access_code": "123456789"
}
```

**Response:**
```json
{
  "token": "abc123...",
  "student_id": "student_123",
  "message": "Connected successfully"
}
```

**Status Codes:**
- `200` — Connected
- `400` — Invalid request
- `401` — Invalid access code
- `429` — Rate limited

---

#### POST /api/packs

Fetch available lesson packs.

**Request:**
```json
{}
```

**Response:**
```json
{
  "packs": [
    {
      "lesson_id": "python_basics.lesson_01",
      "title": "Return Values",
      "version": "1.0"
    }
  ]
}
```

---

#### POST /api/packs/<lesson_id>/download

Download a specific pack.

**Response:**
- Binary ZIP file (`.duckypack`)

---

#### POST /api/submit

Submit student work.

**Request:**
```json
{
  "lesson_id": "python_basics.lesson_01",
  "report": {
    "passed": true,
    "tests_total": 3,
    "tests_passed": 3,
    "duration_seconds": 0.05
  },
  "code": "def add_numbers(a, b):\n    return a + b"
}
```

**Response:**
```json
{
  "status": "submitted",
  "submission_id": "sub_123"
}
```

---

#### POST /api/hint

Request an LLM hint for a failed test.

**Request:**
```json
{
  "lesson_id": "python_basics.lesson_01",
  "test_name": "test_adds_two_numbers",
  "error": "AssertionError: 5 != None",
  "student_code": "def add_numbers(a, b):\n    print(a + b)"
}
```

**Response:**
```json
{
  "hint": "Your function prints the result instead of returning it. Use 'return' instead of 'print'.",
  "level": 1
}
```

---

#### GET /api/llm-status

Check LLM backend status.

**Response:**
```json
{
  "backend": "gemini",
  "model": "gemini-2.5-flash",
  "status": "connected"
}
```

---

#### POST /api/announce

Send an announcement (teacher only).

**Request:**
```json
{
  "message": "New lesson available: Conditionals",
  "class_id": "period_1"
}
```

**Response:**
```json
{
  "status": "announced",
  "announcement_id": "ann_123"
}
```

---

#### GET /api/status

Server status (no auth required).

**Response:**
```json
{
  "status": "running",
  "version": "0.5.0",
  "students_connected": 5
}
```

## Python API

### Runner Module (`src/ducky/runner.py`)

#### `run_pack()`

Run tests against student code.

```python
from ducky.runner import run_pack

report = run_pack(
    pack_path="lesson.duckypack",
    student_file="student.py",
    tutor_engine=None,  # Optional TutorEngine
    timeout_seconds=15
)
```

**Parameters:**
- `pack_path` (str | Path) — Path to .duckypack file
- `student_file` (str | Path) — Path to student's code file
- `tutor_engine` (TutorEngine | None) — Optional tutor for hints
- `timeout_seconds` (int) — Test timeout (default: 15)

**Returns:** `TestRunReport`

---

#### `TestRunReport`

Test run results dataclass.

```python
@dataclass
class TestRunReport:
    lesson_id: str
    title: str
    passed: bool
    returncode: int
    duration_seconds: float
    tests_total: int
    tests_passed: int
    tests_failed: int
    stdout: str
    stderr: str
    failures: list[TestFailure]
    code_redacted: str
```

**Methods:**
- `to_dict(include_raw=False)` — Convert to dictionary

---

#### `TestFailure`

Individual test failure.

```python
@dataclass
class TestFailure:
    name: str
    diagnosis: str
    expected: Any
    actual: Any
    stdout: str
    error: str
    hint: str
```

### Pack Module (`src/ducky/pack.py`)

#### `create_duckypack()`

Create a .duckypack file.

```python
from ducky.pack import create_duckypack, DuckyManifest

manifest = DuckyManifest(
    lesson_id="python_basics.lesson_01",
    title="Return Values",
    entry_file="lesson_01.py",
    concept_tags=["functions", "return_vs_print"]
)

create_duckypack(
    starter_dir="starter/",
    tests_dir="tests/",
    out_path="lesson.duckypack",
    manifest=manifest
)
```

---

#### `DuckyManifest`

Pack manifest dataclass.

```python
@dataclass
class DuckyManifest:
    lesson_id: str
    title: str
    entry_file: str
    language: str = "python"
    pack_version: str = "1.0"
    test_command: str = "python -m pytest tests/"
    concept_tags: list[str] = field(default_factory=list)
    diagnostic_cases: list[dict] = field(default_factory=list)
    instructions: str = ""
```

**Methods:**
- `from_dict(data)` — Create from dictionary
- `to_dict()` — Convert to dictionary

---

#### `unpack_duckypack()`

Extract a .duckypack to a directory.

```python
from ducky.pack import unpack_duckypack

manifest = unpack_duckypack(
    pack_path="lesson.duckypack",
    dest_dir="output/"
)
```

**Returns:** `DuckyManifest`

#### `load_config()`

Load configuration from file.

```python
from ducky.config import load_config

config = load_config()
print(config["llm_backend"])
```

#### `save_config()`

Save configuration updates.

```python
from ducky.config import save_config

save_config({
    "llm_backend": "gemini",
    "gemini_api_key": "your_key_here"
})
```

#### `build_llm_client()`

Create LLM client from config.

```python

client = build_llm_client()
hint = client.generate_hint(request)
```

### LLM Client Module (`src/ducky/llm_client.py`)

Local Ollama LLM client.

```python
from ducky.llm_client import OllamaClient

client = OllamaClient(
    model="qwen2.5-coder:1.5b",
    base_url="http://localhost:11434"
)
```

---

#### `LMStudioClient`

LM Studio client.

```python
from ducky.llm_client import LMStudioClient

client = LMStudioClient(
    model="default",
    base_url="http://localhost:1234",
    max_tokens=2500
)
```

---

#### `GeminiClient`

Google Gemini client.

```python
from ducky.llm_client import GeminiClient

client = GeminiClient(
    api_key="your_api_key",
    model="gemini-2.5-flash"
)
```

---

#### `NoLLMClient`

No-op client (rule-based only).

```python
from ducky.llm_client import NoLLMClient

client = NoLLMClient()
# Always returns empty hint
```

### Tutor Module (`src/ducky/tutor.py`)

#### `TutorEngine`

Generates hints for failed tests.

```python
from ducky.tutor import TutorEngine

engine = TutorEngine(
    llm_client=None,  # Optional LLM client
    remote_client=None  # Optional teacher-proxied client
)

hint = engine.get_hint(
    failure=TestFailure(...),
    instructions="Lesson instructions...",
    student_code="def my_function()..."
)
```

---

### Classroom Module (`src/ducky/classroom.py`)

#### `ClassroomDB`

SQLite database for teacher data.

```python
from ducky.classroom import ClassroomDB

db = ClassroomDB()

# Create class
class_id = db.create_class("Period 1", subject="Python 101")

# Add student
student_id = db.add_student(class_id, "Ada Lovelace")

# Add pack
db.add_pack(class_id, "lesson_01", "Return Values")

# Get submissions
submissions = db.get_submissions(class_id)
```

### Reports Module (`src/ducky/reports.py`)

#### `ReportStore`

Store and retrieve reports.

```python
from ducky.reports import ReportStore

store = ReportStore()

# Save report
store.save(report)

# List reports
reports = store.list_reports(limit=10)

# Get latest
latest = store.get_latest()
```

### Progress Module (`src/ducky/progress.py`)

#### `ProgressTracker`

Track student progress.

```python
from ducky.progress import ProgressTracker

tracker = ProgressTracker()

# Record attempt
tracker.record_attempt("lesson_01", passed=True)

# Get stats
stats = tracker.get_lesson_stats("lesson_01")
print(f"Passed: {stats['passed']}, Failed: {stats['failed']}")

tracker.close()
```

---

### Importer Module (`src/ducky/importer.py`)

#### `import_assignment()`

Import an assignment into the workspace.

```python
from ducky.importer import import_assignment

result = import_assignment(
```
