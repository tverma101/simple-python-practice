# Lesson 02: Conditionals

## Goal
Write a function that uses an `if` statement to return `True` or `False`.

## Instructions

Complete the `is_positive(n)` function so it returns `True` if `n > 0` and `False` otherwise.

### Example
```python
is_positive(5)   # True
is_positive(-3)  # False
is_positive(0)   # False
```

### Hint
Use an `if` statement to check the condition, then `return True` or `return False`.
